
The Job Application Tracker project was developed using HTML, CSS and JavaScript to help users manage their job applications efficiently. The main objective of this project is to create a simple and user-friendly web application where users can add company names, job roles and application statuses.

During the Testing and Quality Assurance phase, the application is reviewed to check its functionality, usability and reliability. The testing process focuses on important features such as adding job applications, displaying application details, searching records, deleting applications and updating dashboard statistics.

The application provides four job statuses: Applied, Interview, Selected and Rejected. The dashboard displays the total number of applications, interviews and selected applications. JavaScript is used to handle user interactions, while LocalStorage is used to save application information in the browser.

The testing plan includes functional testing, input validation, search testing, deletion testing and browser refresh testing. Each feature is checked against its expected result to identify errors and improve reliability. Any identified issues are corrected and the affected features are tested again.

The project was developed and tested using Visual Studio Code and a web browser. This phase helps improve my practical knowledge of software testing, debugging, quality assurance and frontend development.

Through this project, I gained practical experience in developing interactive web applications and understanding the importance of testing software before delivery. Future improvements may include editing application details, adding application dates and integrating a database.
